# فحص محلي لمزامنة التصدير

أداة تشخيص اختيارية، لا تعمل على حسابات المستخدمين ولا تُشغّل الأتمتة ولا ترفع أو تنشر فيديو. تخدم نسخة `public` محليًا، وتمنع طلبات المتصفح خارج الخادم المحلي، وتستبدل التلاوة بثلاث نغمات اصطناعية مدة كل منها ثانيتان. أثناء الرسم فقط، تضيف علامة لونية في زاوية الإطار تدل على فهرس الآية الذي يرسمه الصانع. تُحذف ملفات الاختبار المؤقتة بعد التحليل.

## التشغيل

بعد تثبيت تبعيات المشروع وتوفير `ffmpeg` في PATH:

```sh
node tools/render_sync_diagnostic.js                   # افتراضيًا 720p
node tools/render_sync_diagnostic.js --quality=1080     # 1080 × 1920
node tools/render_sync_diagnostic.js --no-gpu
node tools/render_sync_diagnostic.js --quality=1080 --no-gpu --stall-ms=1500
```

إذا لم يكن `ffmpeg` في PATH يمكن تحديد مساره بالمتغير `FFMPEG`. تعتمد الأداة على `playwright-core` و`@sparticuz/chromium`؛ قد يحتاج Chromium إلى مكتبات النظام المناسبة حسب البيئة. خيار `--no-gpu` يستخدم في الاختبار فقط، ولا يغيّر إعدادات التطبيق أو الإنتاج. خيار `--stall-ms` يفتعل تعليقًا في خيط الواجهة عند بداية التشغيل لاختبار الضغط؛ لا يمثل بالضرورة جهازًا حقيقيًا.

يعرض التقرير الجودة المختارة وأبعاد اللوحة المستخدمة، وتُفك إطارات الفيديو إلى عينات بمعدل 10 في الثانية وتُقارن العلامة في كل عينة بتردد الصوت في نافذة 100ms. يوضح JSON النوافذ المتطابقة وغير المتطابقة والعلامات والنغمات غير المصنّفة ونوافذ الصمت، وأجزاء الصوت أو الفيديو التي لم يشملها التحليل بسبب اختلاف الطول. النتيجة تقريبية؛ يمكن أن تظهر نافذة اختلاف عند حدود المقاطع بسبب التقطيع والتقريب. العلامة تعكس **فهرس الرسم** لا وضوح النص أو صحته، وإضافتها نفسها قد تؤثر في أداء الرسم. عينات الاختبار الاصطناعية لا تثبت التزامن في تلاوة حقيقية أو جهاز آخر أو خادم الإنتاج. لا تستنتج النجاح لمجرد غياب الاختلافات: افحص المقاطع غير المحللة والعلامات غير المصنفة أيضًا. الحقل `all_tones_sampled` يعني فقط أن كل تردد ظهر في نافذة واحدة على الأقل من الجزء المقارن؛ لا يعني أن كامل المقطع قد فُحص. إذا غابت إحدى النغمات عن الجزء المقارن، تطبع الأداة تقرير JSON غير مكتمل وتخرج بالرمز 2؛ لا تعتبر ذلك نجاحًا.

يعرض `native_frame_timing` عدد إطارات الفيديو المفكوكة قبل إعادة أخذ العينات، ووقتي أول وآخر إطار، ومتوسط الإطارات بينهما وأطول فترة بين إطارين متتاليين. المتوسط هو عدد الفواصل مقسومًا على زمن أول وآخر إطار، ولا يشمل مدة عرض الإطار الأخير. عند غياب توقيت أو تكراره أو رجوعه يُعلّم `timestamp_order_valid` بأنه غير صالح وتكون مقاييس الفترة والمتوسط `null`. هذه أزمنة الإطارات المحفوظة، ولا تكشف وحدها إطارات متطابقة أو تجمّد المحتوى؛ عيّنات `fps=10` قد تكرّر أو تحذف إطارات، فلا تستخدم عددها لحساب معدل الإطارات الأصلي. لا توجد عتبة نجاح تلقائية لهذه القيم.

اختبار منطق التحليل دون Chromium أو ffmpeg:

```sh
node tests/render_sync_diagnostic_test.js
```

واختبار اختياري لتوقيت الإطارات بملف اصطناعي متغير التوقيت (يتطلب `ffmpeg` مع `lavfi` و`libvpx-vp9`):

```sh
node tests/render_sync_frame_timing_integration_test.js
```
