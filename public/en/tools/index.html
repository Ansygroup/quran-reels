FAQ

Are these tools really free?

Yes — every tool is free with no signup, no watermarks and no daily limits. The project is voluntary.

Do I need to install an app?

No. The tools run in your browser and work offline once the page has loaded; you can also install this site as an app from your browser menu.

Are the calculations reliable?

The calculators implement standard formulas and let you pick the method or school where opinions differ. For specific rulings, always confirm with a knowledgeable scholar.

Is there an Arabic version?

Yes — the full Arabic tools index is at /ar/islamic-tools/, and each tool can be switched between Arabic and English inside the app.
