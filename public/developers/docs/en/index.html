Quran Reels Developers — API (English)

A single stateless endpoint: POST JSON-RPC 2.0 to /api/mcp — no key, no account, no rate-limit claims. Six tools covering prayer times, qibla, hijri date, verses (Uthmani up to 10 ayat), and pre-filled reel-maker links.

KeylessJSON-RPC 2.0Stateless

Quick start

POST /api/mcp
{"jsonrpc":"2.0","id":1,
"method":"tools/call","params":{"name":"get_prayer_times","arguments":{"city":"Cairo","country":"EG"}}}

  • Discovery: /.well-known/mcp.json lists the server capabilities.
  • tools/list: returns the six tool schemas (name, arguments, description).
  • tools/call: invokes one tool; errors come back as JSON-RPC errors (400 on malformed JSON).
  • Full guide: MCP docs (Arabic) · site: Quran Reels (Arabic UI).

الأسئلة الشائعة

Authentication?

None — the endpoint is keyless and stateless.

Which tools exist?

get_prayer_times, get_qibla, get_hijri_date, get_verse, create_reel, and quran_reel_maker_info (facts).

Data freshness?

Computed per request (Aladhan-based algorithms, Uthmani text) — no cached user data is stored.
