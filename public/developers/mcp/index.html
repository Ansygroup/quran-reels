اختبار سريع بـ curl (JSON-RPC)

curl -s -X POST https://quran-reels-tau.vercel.app/api/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

# استدعاء فعلية — قبلة القاهرة:
curl -s -X POST https://quran-reels-tau.vercel.app/api/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call",
       "params":{"name":"get_qibla","arguments":{"latitude":30.0444,"longitude":31.2357}}}'

ملاحظات تقنية

  • النقل: Streamable HTTP — POST لجسم JSON-RPC 2.0، ردّ JSON مباشر (لا يحتاج SSE)، تنبيهات (notifications/*) بـ202 Accepted.
  • بدون جلسة: لا رأس Mcp-Session-Id مطلوب — كل طلب مستقل (stateless)، فلا تُخزَّن أي بيانات محادثة.
  • البروتوكولات المدعومة: 2025-06-18 · 2025-03-26 · 2024-11-05 (يُرجَع إصدار العميل إن كان مدعومًا).
  • الطرق: initialize · ping · tools/list · tools/call — غيرها -32601.
  • عمر الردّ: حساب المواقيت/القبلة/الهجري داخل الاستجابة (بلا انتظار خارجي)، وget_verse وحده يستدعي alquran.cloud.

الأسئلة الشائعة

هل أحتاج مفتاح API أو حسابًا؟

لا — نقطة النهاية عمومية ومجانية بالكامل (نفس روح الموقع: صدقة جارية بلا حدود).

هل يمكن للمساعد «ينشئ» الفيديو بدلًا من الرابط؟

التصدير الفعلي يحتاج متصفحك (Canvas + MediaRecorder)، لذا يُرجع create_reel رابطًا مسبق التعبئة يفتح المولّد على النطاق المطلوب جاهزًا — خطوة واحدة ثم إنشاء وتحميل.

ما الذي يضمن صحة الأجوبة؟

المعادلات نفسها المستخدمة في واجهة الموقع (أم القرى، الكرة الأسطوية، Intl أم القرى) — وقد دُرّبت مقابل مرجع Aladhan بفارق ٠–٢ دقيقة في فحص صحة يومي.

هل أستطيع بناء عميل خاص بي؟

نعم — أي مكتبة MCP (Python/TypeScript) تتحمّل هذا العنوان كـstreamable_http_server؛ أو استدعِ JSON-RPC مباشرة كما في أمثلة curl أعلاه.
